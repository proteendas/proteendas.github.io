Road2Walk for iPhone

Free install through AltStore, no App Store needed.

1. Set up AltStore (once)

  1. On your Mac or Windows PC, install AltServer and install AltStore onto your iPhone (it signs in with your own Apple ID).
  2. Keep AltServer running on the same Wi-Fi so it can refresh the app.

2. Add Road2Walk

Add to AltStore Add to SideStore Or in AltStore: Browse → Sources → + and paste

Good to know

  • Free Apple IDs expire apps after 7 days. AltStore refreshes them automatically while AltServer is reachable.
  • A free Apple ID allows 3 sideloaded apps at a time.
  • Push notifications don't work on sideloaded builds. Alerts still arrive in the app in real time.
